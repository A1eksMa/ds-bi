# Changelog

Архивы в этой папке — рабочая версия кода (без тестов), готовая к распаковке и запуску.
Имя архива содержит номер версии: `ds-bi-<version>.tar.gz`.

Для машины без git: скачать один архив вместо файлов по отдельности.

## Распаковка

```bash
mkdir -p /path/to/target/folder
tar -xzf ds-bi-<version>.tar.gz -C /path/to/target/folder
```

Внутри: `src/`, `queries/`, `pyproject.toml`, `LICENSE`, `README.md`.

## Запуск

```bash
# если есть pip
pip install -e /path/to/target/folder
ds-bi --db /path/to/data.db catalog/sources

# без pip
PYTHONPATH=/path/to/target/folder python3 -m src.cli --db /path/to/data.db catalog/sources
```

Полностью — `docs/reference/cli.md` в репозитории.

## 0.1.0a1 — `ds-bi-0.1.0a1.tar.gz`

Первая версия. Почти полный переписанный прототип (исходно — набросок на несколько
итераций с нейросетями), сохранивший основную идею — пул сохранённых `.sql`-запросов с
параметрами `:name` (значения) и `{name}` (идентификаторы, с подстановкой через точечную
регэксп-замену, а не `str.format()` — не ломается на случайном JSON-литерале в запросе).

- Группировка запросов по папкам произвольной вложенности (`queries/crm/revenue/top.sql` —
  адресуется путём `crm/revenue/top`) вместо плоского каталога.
- Интерактивная навигация по дереву номерами (с количеством запросов в каждой подпапке),
  либо ввод пути целиком с любого уровня — пропускает навигацию.
- Одна строка вызова с путём и всеми параметрами сразу — без единого интерактивного
  запроса, если все параметры запроса переданы.
- Экспорт результата: `--format table|json|csv`, `--out PATH` — в файл вместо терминала.
  `csv` всегда в `utf-8-sig` (BOM) — иначе Excel на Windows показывает кириллицу как мусор.
  `NULL` в CSV — пустая ячейка, не строка `"None"`.
- `--db`/`--queries-dir` настраиваются флагом или переменными окружения `DS_BI_DB` /
  `DS_BI_QUERIES_DIR`.
- Доступ к `data.db` — без ограничений на запись (инструмент разработчика, полная
  ответственность на том, кто пишет/запускает `.sql`-файл).
- Примеры запросов на реальной схеме `ds` (`srcs`/`lbs`/`transactions`/...) — `queries/`.
- 67 тестов (`tests/`), stdlib-only, Python `>= 3.9` (как и `ds`/`ds-loader`).
